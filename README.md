
# WaterRocket
This a build for a WaterRocket with launch mechanism. A WaterRocket is basically a plastic bottle (opening turned to the bottom) filled with some water and under pressure. When the pressure is released, the
bottle flies into the air thanks to the water that pushes through the opening.

Elements under pressure can explode, or cause damage, so please pay attention. This build is a mechanism to retain the rocket (instead of a human) it for a safe takeoff

It Still has NOT been tested completely, but will be tested shortly and modified if there are any problem

# The Rocket

The Rocket itself is made out of 6 different parts (see BOM) : A 2L bottle (design for coca cola), 2 (different) 3d printed rings and 3 of the same 3d printed fins.

# The launch mechanism

Built to use the less components possible and easy to assemble, it holds only 9 components total (5 are 3d printed and 4 to buy : see BOM).
